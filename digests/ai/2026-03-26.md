[**Karpathy Flags a Fundamental Memory Problem Plaguing All LLMs**](https://x.com/karpathy/status/2036836816654147718)
Andrej Karpathy called out a persistent personalization failure across all LLMs: a single past query can haunt a model's responses indefinitely, getting dragged into unrelated conversations via naive RAG-style memory retrieval. He suspects the root cause is either poor top-k embedding retrieval or a training-induced bias where models over-rely on whatever lands in the context window. The fact that every major LLM exhibits this behavior suggests the issue is systemic, not implementation-specific.
_Why it matters: Memory and personalization are key battlegrounds for AI assistant differentiation, and if Karpathy's diagnosis is right, the whole field has a shared architectural problem to solve._
→ [@karpathy](https://x.com/karpathy/status/2036836816654147718)
