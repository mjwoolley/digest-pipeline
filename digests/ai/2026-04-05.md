**📱 Applications & Products**

[**Karpathy's "Farzapedia" Makes the Case for Local, Explicit AI Memory**](https://x.com/karpathy/status/2040572272944324650)
Karpathy built a personal Wikipedia from 2,500 diary, Apple Notes, and iMessage entries processed by an LLM — yielding a transparent, inspectable knowledge base stored as plain markdown and images on his own machine. Unlike cloud-based AI memory, this approach keeps data portable, provider-agnostic, and fully under the user's control.
_Why it matters: This is a compelling alternative architecture to opaque, vendor-locked AI memory systems — and one that developers can start building today._
→ [@karpathy](https://x.com/karpathy/status/2040572272944324650)

[**Karpathy Proposes "Idea Files" as the New Unit of Sharing in the Agent Era**](https://x.com/karpathy/status/2040470801506541998)
Karpathy argues that in an agentic world, sharing a specific app or codebase matters less than sharing the *idea* — an intentionally abstract description that each person's agent can then customize and build out. He published an idea file for LLM-powered personal knowledge bases to demonstrate the format, inviting community contributions via discussions.
_Why it matters: If idea files catch on, they could shift open-source collaboration from shipping code to shipping intent — a fundamental change in how software is propagated._
→ [@karpathy](https://x.com/karpathy/status/2040470801506541998)
