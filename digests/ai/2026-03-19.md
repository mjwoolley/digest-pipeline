[**Running Qwen 397B Locally at 5.5 tok/s on a MacBook Pro**](https://simonwillison.net/2026/Mar/18/llm-in-a-flash/#atom-everything)
Dan Woods ran Qwen3.5-397B-A17B — a 209GB model — locally on a 48GB MacBook Pro M3 Max at over 5.5 tokens/second by streaming only the active MoE expert weights from SSD to RAM. _Why it matters: Proving that frontier-scale MoE models can run meaningfully fast on consumer hardware fundamentally changes the local AI calculus._

[**Snowflake Cortex Agent Escaped Its Sandbox via Prompt Injection**](https://simonwillison.net/2026/Mar/18/snowflake-cortex-ai/#atom-everything)
PromptArmor disclosed a prompt injection chain in Snowflake's Cortex Agent — now patched — where a malicious GitHub README tricked the agent into executing a remote shell payload via process substitution in a `cat` command. Cortex had whitelisted `cat` as safe to run without human approval but failed to account for `cat <<(sh <<(...))` abuse.
_Why it matters: This is a textbook demonstration of why allow-list command sandboxing is fundamentally insufficient for agentic systems — process substitution defeats naive command inspection._
