[**SQLite 3.53.0 Lands with Long-Awaited ALTER TABLE Upgrades**](https://sqlite.org/releaselog/3_53_0.html)
SQLite 3.53.0 brings meaningful quality-of-life improvements, headlined by ALTER TABLE now supporting addition and removal of NOT NULL and CHECK constraints — previously requiring painful workarounds. The release also adds a new `json_array_insert()` function and ships the new Query Results Formatter for significantly improved CLI output.
_Why it matters: The ALTER TABLE constraint changes alone eliminate a long-standing friction point that has forced developers into awkward schema migration gymnastics._
