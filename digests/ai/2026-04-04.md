[**AI Agents Will Industrialize Zero-Day Discovery — "Vulnerability Research Is Cooked"**](https://simonwillison.net/2026/Apr/3/vulnerability-research-is-cooked/#atom-everything)
Security researcher Thomas Ptacek argues that within months, coding agents will fundamentally break the economics of exploit development — not gradually, but as a step function. Frontier LLMs are naturally suited to vulnerability research because finding bugs is essentially pattern-matching across source code and constraint-solving for reachability, exactly what these models do best. Agents don't get bored, can search indefinitely, and produce straightforwardly testable results.
_Why it matters: When "find me zero-days in this repo" becomes a viable command, the entire security industry's threat model needs to be rebuilt from scratch._

[**Anthropic's "Model Diff" Technique Spots Ideological Features Unique to Each AI**](https://t.co/gz1i1Oy8ZI)
